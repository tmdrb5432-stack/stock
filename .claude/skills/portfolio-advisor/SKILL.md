# 포트폴리오 어드바이저 스킬

## 개요

사용자(승규)가 실제로 보유한 주식/코인 종목의 수량과 평균매수가를 기준으로:
1. 보유 종목 관련 뉴스 브리핑
2. 기술적 매수/매도 신호 분석
3. 보유 비중·손익 기반 리밸런싱 제안
4. 재무제표/펀더멘털 분석

을 제공한다. 결과는 채팅창에 즉시 출력한다.

> ⚠️ **현재 제약**: 이 스킬은 사용자가 별도로 만든 "로컬 주식/코인 매수알람시스템"에 아직 연동되어 있지
> 않다. 클라우드(원격) 세션에서는 사용자 PC의 로컬 시스템에 직접 접근할 수 없기 때문이다. 향후 로컬
> Claude Code 세션에서 해당 시스템의 입출력 형식(파일/웹훅/DB 등)을 확인한 뒤 연동을 추가할 것.
> 그 전까지는 채팅창 출력이 유일한 결과물이다.

> ⚠️ **데이터 소스**: 이 세션에는 증권 시세나 코인 시세를 위한 전용 MCP 도구가 연결되어 있지 않다.
> 모든 시세/뉴스/재무 데이터는 `web_search`(및 필요 시 `web_fetch`)로 조회한다. 만약 향후 세션에
> Crypto.com MCP나 증권 데이터 MCP 등 전용 도구가 연결되어 있다면, web_search보다 그 도구를 우선
> 사용한다.

## 보유 포트폴리오 기본 설정

> ⚠️ 아래 표는 **예시 플레이스홀더**다. 승규가 실제 보유 내역(종목명, 티커, 수량, 평균매수가)을
> 알려주면 이 표를 갱신해서 사용한다. 표가 비어 있거나 예시 상태인 채로 분석 요청이 들어오면, 먼저
> 실제 보유 내역을 물어본 뒤 진행한다.

### 보유 주식
| # | 종목명 | 티커 | 수량 | 평균매수가 |
|---|--------|------|------|-----------|
| 1 | (예시) 삼성전자 | 005930 | 0 | 0 |

### 보유 코인
| # | 심볼 | 수량 | 평균매수가(USD) |
|---|------|------|----------------|
| 1 | (예시) BTC | 0 | 0 |

> 💡 승규가 "종목 추가해줘", "수량 바꿔줘", "매도했어" 등으로 요청하면 이 표를 대화 중 반영한다.

## 실행 모드

이 스킬은 4가지 모드로 동작한다. 사용자의 요청 문구에 따라 적절한 모드(복수 선택 가능)를 실행한다.

| 모드 | 트리거 예시 |
|------|-------------|
| A. 뉴스/시황 브리핑 | "보유종목 뉴스 브리핑", "내 종목들 오늘 어때" |
| B. 기술적 매수/매도 신호 | "매수 신호 있어?", "지금 팔아야 할까?", "골든크로스 됐어?" |
| C. 포트폴리오 리밸런싱 | "포트폴리오 점검해줘", "리밸런싱 필요해?", "비중 어때" |
| D. 재무제표/기업 분석 | "재무제표 분석해줘", "PER PBR 확인해줘", "이 회사 재무 어때" |

여러 모드가 동시에 해당하면 (예: "포트폴리오 전체 점검해줘") A → B → C → D 순서로 모두 실행하고
마지막에 종합 요약을 덧붙인다.

---

### [모드 A] 뉴스/시황 브리핑

#### Step 1. 보유 종목별 뉴스 스캔
- 보유 주식/코인 각각에 대해 `web_search`로 최근 뉴스 검색
- 검색 쿼리 예: `{종목명} 뉴스 오늘`, `{종목명} 주가 전망`, `{코인심볼} 시세 오늘`
- **이슈 있는 종목만** 추출해서 출력 (무이슈 종목은 생략, 노이즈 제거)

**출력 형식:**
```
📊 [오늘 날짜] 보유종목 뉴스 브리핑
─────────────────────────
🔴 [종목명] - [한 줄 요약] → 판단: 매도 고려
🟡 [종목명] - [한 줄 요약] → 판단: 중립
🟢 [종목명] - [한 줄 요약] → 판단: 추가매수 관심
─────────────────────────
이슈 없음: [종목 나열]
```

**판단 기준:**
| 신호 | 판단 |
|------|------|
| 실적 어닝서프라이즈, 신사업 발표, 대형 계약 | 🟢 추가매수 관심 |
| 특이사항 없음, 시장 흐름과 동행 | 🟡 중립 |
| 실적 쇼크, 규제 이슈, 대주주 매도, 악재 공시 | 🔴 매도 고려 |

---

### [모드 B] 기술적 매수/매도 신호

#### Step 1. 시세/차트 데이터 확보
- 전용 시세 MCP가 있으면 그것으로 캔들 데이터(가급적 주봉)를 가져온다.
- 없으면 `web_search`로 `{종목명/심볼} 주봉 차트`, `{종목명} 이동평균선` 등을 검색해 최근 추세를
  파악한다. 정확한 수치 계산이 어려우면 기사/차트 분석 코멘트를 근거로 정성적 판단을 내리고 그
  사실을 명시한다.

#### Step 2. 골든/데드크로스 판단 (수치 확보 시)
- 단기 이동평균: 20주 MA / 장기 이동평균: 60주 MA
- 골든크로스: 20MA가 60MA를 아래에서 위로 돌파 → 매수 신호
- 데드크로스: 20MA가 60MA를 위에서 아래로 돌파 → 매도/주의 신호
- 60주치 데이터가 부족하면 보유 데이터 기준으로 계산 후 "데이터 부족" 표기

**출력 형식:**
```
📈 기술적 매수/매도 신호
─────────────────────────
⭐ 골든크로스 감지: [종목/코인] 20MA > 60MA → ✅ 매수 신호
⚠️ 데드크로스 감지: [종목/코인] 20MA < 60MA → ❌ 매도 주의
📊 현재 위치: [종목/코인] 추세 코멘트
─────────────────────────
```

---

### [모드 C] 포트폴리오 리밸런싱

#### Step 1. 현재가 조회
각 보유 종목/코인의 현재가를 `web_search`(또는 시세 MCP)로 조회한다.

#### Step 2. 비중·손익 계산
```
평가금액 = 수량 × 현재가
평가손익 = (현재가 - 평균매수가) × 수량
평가손익률(%) = (현재가 - 평균매수가) / 평균매수가 × 100
포트폴리오 내 비중(%) = 해당 종목 평가금액 / 전체 평가금액 합 × 100
```

#### Step 3. 경고 조건 및 제안
| 상황 | 제안 |
|------|------|
| 단일 종목 비중이 전체의 30% 초과 | ⚠️ 쏠림 경고, 비중 축소(일부 익절/분산) 제안 |
| 평가손실률 -20% 이하 | ⚠️ 손절/추가 검토 필요 (뉴스·펀더멘털 재확인 권장) |
| 특정 자산군(주식 vs 코인) 비중이 과도하게 한쪽에 쏠림 | 자산배분 재검토 제안 |
| 위 조건에 해당 없음 | 특이사항 없음으로 표기 |

**출력 형식:**
```
💼 포트폴리오 현황
─────────────────────────
[종목명]  수량 X  평가금액 X원  손익 ±X% (±X원)  비중 X%
...
─────────────────────────
🎯 리밸런싱 제안
- [종목명]: [제안 내용 + 이유]
─────────────────────────
```

---

### [모드 D] 재무제표/기업 분석

코인은 이 모드의 대상이 아니다(코인은 A/B/C 모드로 분석). 보유 주식 종목에 대해서만 실행한다.

#### Step 1. 핵심 지표 조회
`web_search`로 `{종목명} PER PBR ROE 부채비율`, `{종목명} 최근 실적` 등을 검색해 아래 지표를 최대한
확보한다:
- PER (주가수익비율), PBR (주가순자산비율), ROE (자기자본이익률), 부채비율, 최근 분기 매출/영업이익 증감

#### Step 2. 판단 기준
| 지표 | 참고 기준 |
|------|-----------|
| PER | 업종 평균 대비 낮으면 저평가 가능성, 높으면 고평가 가능성 (성장주는 예외적으로 높을 수 있음) |
| PBR | 1 미만이면 장부가 대비 저평가 신호로 참고 |
| ROE | 높을수록 자본 효율성이 좋음 (10% 이상이면 양호로 참고) |
| 부채비율 | 200% 초과 시 재무 안정성 주의 |
| 실적 추세 | 매출/영업이익 연속 증가는 긍정적 신호 |

지표는 업종마다 적정 범위가 다르므로, 가능하면 동일 업종 경쟁사와 비교한 상대적 코멘트를 함께
제공한다.

**출력 형식:**
```
📑 [종목명] 재무 분석
─────────────────────────
PER: X배 (업종평균 대비 ...)
PBR: X배
ROE: X%
부채비율: X%
최근 실적: [한 줄 요약]
─────────────────────────
🎯 종합 코멘트: [저평가/고평가/중립 + 근거]
─────────────────────────
```

## 종합 요약 (여러 모드 동시 실행 시)

```
🎯 오늘의 액션 아이템
─────────────────────────
매수/추가매수 검토: [종목 나열 + 이유 한 줄]
매도/축소 검토: [종목 나열 + 이유 한 줄]
리밸런싱 제안: [핵심 제안 1~2개]
모니터링: [주목할 이슈/신호]
─────────────────────────
⚠️ 본 분석은 투자 참고용이며, 최종 판단은 본인이 직접 하세요.
```

## 출력 원칙

- 채팅창에 바로 출력 (현재는 로컬 알람 시스템 연동 없음, Gmail 발송도 하지 않음)
- 이모지 활용해 가독성 높이기
- 이슈/특이사항 없는 항목은 요약 생략 (노이즈 제거)
- 판단은 항상 "참고용"임을 명시
- 보유 포트폴리오 표가 예시(플레이스홀더) 상태면, 분석 전에 실제 보유 내역을 먼저 확인

## 오류 처리

| 상황 | 대응 |
|------|------|
| 보유 포트폴리오 표가 비어있거나 예시 상태 | 실제 보유 종목/수량/매수가를 먼저 질문 |
| 시세/재무 데이터 검색 실패 | "데이터 조회 실패"로 표기하고 가능한 범위에서 분석 계속 |
| 이동평균 계산용 데이터 부족 (60주 미만) | 보유 데이터 기준으로 계산 후 "데이터 부족" 표기 |
| 특정 종목/코인 심볼 미지원 또는 검색 결과 없음 | 사용자에게 안내 후 다른 검색어로 재시도 |
| 코인 종목에 모드 D(재무제표) 요청 | 코인은 재무제표 대상이 아님을 안내하고 모드 A/B/C로 대체 제안 |
