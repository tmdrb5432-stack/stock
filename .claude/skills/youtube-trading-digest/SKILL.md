# 유튜브 트레이딩 다이제스트 스킬

## 개요

지정된 유튜브 채널·재생목록에서 최근 영상들의 자막을 가져와, 영상 안에서 언급된 종목/코인에 대한
트레이딩 관점(매수/매도/관망, 근거, 목표가나 기간 언급 여부)을 추출해 채널별로 요약한다.
`portfolio-advisor` 스킬과는 별도로 동작하지만, 사용자의 보유 종목과 겹치는 언급이 있으면 강조해서
보여준다.

## 실행 전제 조건 (중요)

이 스킬은 **로컬 Claude Code**(사용자 PC, 네트워크 제한 없음)에서 실행되는 것을 전제로 만들어졌다.

- youtube.com에 직접 접속해서 영상 목록·자막을 가져와야 하는데, 클라우드/원격 세션은 조직 네트워크
  정책상 youtube.com 자체가 차단되어 있는 경우가 있다 (실제로 이 스킬을 만들 당시 원격 세션에서
  `youtube.com`, `downsub.com`, `youtubetranscript.com`이 모두 403 정책 차단으로 확인됨).
- 이 스킬을 실행하기 전에 `python3 -c "import socket; socket.create_connection(('www.youtube.com', 443), timeout=5)"` 같은
  방식으로 접속 가능 여부를 먼저 확인하거나, 그냥 `scripts/fetch_transcripts.py`를 실행해보고 네트워크
  오류가 나면 "이 환경에서는 youtube.com 접근이 막혀 있어 이 스킬을 실행할 수 없다"고 사용자에게
  알려준다. 억지로 우회를 시도하지 않는다.
- 필요한 패키지가 없으면 먼저 설치 안내: `pip install yt-dlp youtube-transcript-api`

## 대상 채널/재생목록

> 승규가 지정한 소스. 채널/재생목록이 바뀌면 이 표를 갱신한다.

| # | 이름 | URL |
|---|------|-----|
| 1 | 차트버거형 | https://www.youtube.com/@chart-burgerbro |
| 2 | 인범티비 | https://www.youtube.com/@inbumtv |
| 3 | (재생목록) | https://www.youtube.com/playlist?list=PLVups02-DZEWWyOMyk4jjGaWJ_0o1N1iO |

## 실행 단계

### Step 1. 최근 영상 + 자막 수집

`scripts/fetch_transcripts.py`를 실행한다 (Bash 도구 사용):

```bash
python3 .claude/skills/youtube-trading-digest/scripts/fetch_transcripts.py \
  "https://www.youtube.com/@chart-burgerbro" \
  "https://www.youtube.com/@inbumtv" \
  "https://www.youtube.com/playlist?list=PLVups02-DZEWWyOMyk4jjGaWJ_0o1N1iO" \
  --limit 5
```

- `--limit`은 소스당 가져올 최근 영상 개수 (기본 5, 특별 요청 없으면 5 유지)
- 결과는 JSON 배열로 stdout에 출력된다. 각 항목: `source`, `video_id`, `title`, `upload_date`,
  `url`, `transcript`(자막 텍스트 또는 null), `transcript_error`(자막 실패 사유 또는 null)

### Step 2. 영상별 트레이딩 관점 추출

각 영상의 `transcript`를 읽고 다음을 추출한다:
- 언급된 종목명/티커 또는 코인 심볼
- 방향성: 매수 관심 / 매도·차익실현 고려 / 관망·중립
- 근거 한두 줄 (기술적 근거, 뉴스/이슈, 수급 등)
- 목표가·기간이 언급됐다면 함께 기록

`transcript`가 null이면(`transcript_error` 있음) 자막이 없다는 뜻이다. 이 경우 영상 제목만으로
추정하지 말고 "자막 없음 — 제목 기준 참고만 가능"으로 표기하고, 필요하면 제목에서 유추되는 종목/주제만
언급한다.

### Step 3. 채널별 요약 출력

**출력 형식:**
```
🎬 [채널명] 최근 영상 트레이딩 관점 ([N]개 영상)
─────────────────────────
📌 [영상 제목] ([업로드일])
   종목/코인: [이름]  방향: 🟢매수 / 🔴매도 / 🟡관망
   근거: [한두 줄 요약]
   목표가/기간: [언급 있으면 표기, 없으면 생략]
   링크: [url]
─────────────────────────
(자막 없는 영상은 "자막 없음"으로 별도 표기)
```

### Step 4. 채널 간 종합 코멘트

모든 채널 분석이 끝나면:
- 여러 채널에서 공통으로 언급된 종목/코인이 있으면 강조 (의견 일치 = 신뢰도 참고용으로 상향)
- 채널 간 의견이 엇갈리는 종목이 있으면 그 사실을 명시 (예: "A채널은 매수, B채널은 매도 관점")
- `portfolio-advisor`의 보유 종목 표(있다면)와 겹치는 언급이 있으면 "⚠️ 보유 종목 관련 언급"으로 별도 강조

```
🎯 채널 종합 요약
─────────────────────────
공통 언급 (여러 채널 일치): [종목/코인 + 방향 + 이유]
의견 엇갈림: [종목/코인 + 채널별 입장]
⚠️ 내 보유 종목 관련 언급: [있으면 표기, 없으면 생략]
─────────────────────────
⚠️ 유튜버 개인 의견이며 투자 참고용입니다. 최종 판단은 본인이 직접 하세요.
```

## 출력 원칙

- 채팅창에 바로 출력
- 자막 원문을 그대로 길게 인용하지 않고, 트레이딩 관점 중심으로 압축 요약
- 영상이 트레이딩과 무관한 내용(잡담, Q&A 등)이면 "트레이딩 관련 언급 없음"으로 짧게 표기하고 생략
- 여러 영상에서 같은 종목을 반복 언급하면 최신 영상 기준으로 정리하되 의견이 바뀌었다면 그 변화를 언급

## 오류 처리

| 상황 | 대응 |
|------|------|
| youtube.com 접속 자체가 안 됨 (원격/제한된 네트워크) | 로컬 Claude Code에서 실행해야 한다고 안내하고 중단 |
| `yt-dlp` 또는 `youtube-transcript-api` 미설치 | 설치 명령(`pip install yt-dlp youtube-transcript-api`) 안내 |
| 특정 영상 자막 비활성화/없음 | 해당 영상만 "자막 없음"으로 표기하고 나머지는 계속 진행 |
| 채널/재생목록 URL이 바뀌었거나 삭제됨 | 사용자에게 최신 URL 확인 요청 |
| 영상이 너무 많아 자막 수집이 오래 걸림 | `--limit`을 낮춰서(예: 3) 재시도 제안 |
